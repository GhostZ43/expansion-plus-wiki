Getting started

Getting started#

Requirements#

Mod Workshop ID Why
Community Framework (CF) 1559212036 Core framework, file access
Dabs Framework 2545327648 Needed by Expansion's UI
DayZ-Expansion-Licensed 2116157322 Expansion core
DayZ-Expansion-Bundle 2572331007 Market, Base Building and Navigation are used

Note

The Expansion ATM must be on. Set "ATMSystemEnabled": 1 in profiles/ExpansionMod/Settings/MarketSettings.json. Banking, shops, rent, fees and online pay all use the Expansion bank.

Install on the server#

  1. Copy @GhostzSuite into your server folder.
  2. Copy @GhostzSuite/keys/Ghostz.bikey into the server's keys folder.
  3. Load it last, after Expansion and after any PvE mod: -mod=@CF;@Dabs Framework;@DayZ-Expansion-Licensed;@DayZ-Expansion-Bundle;@GhostzSuite
  4. Start the server once. It creates profiles/GhostzSuite/ and profiles/GhostzQoLPlus/.

Warning

Do not load @GhostzQoLPlus with Expansion Plus 1.20 or later. Its code is already inside, and loading both stops the server starting.

Players#

Players subscribe on the Steam Workshop (ID 3832964217). The tablet, map drawing and sounds run on each player's game, so players always need the same version as the server.

Your first admin#

  1. Start the server once. It creates profiles/GhostzSuite/Settings.json.
  2. Stop the server and add your Steam64 ID to Admins: json "Admins": ["76561198000000000"]
  3. Start the server, join and press F8.

After that, add or remove admins in game on F8 → SETTINGS (ADD MY ID adds yourself). Admins in Expansion Plus are admins of the Workshop apps too. If someone who isn't an admin presses F8, the panel shows them their Steam64 ID so they can send it to you. Narrower roles are covered in Admin panel.

Make the shop kit buyable#

Players open a shop with a Player Shop Kit. Add it to a trader:

  1. Press F8 and open MARKET.
  2. Edit a category and add an item with the classname gzs_playershopkit, with a price and stock.
  3. Make sure that category is in a trader, then restart.

Keys#

Key Does
F7 The tablet
F5 The tablet, open on the Workshop hub
F8 Admin panel (admins only)
F9 Server info
K Garage
Numpad 0 Cruise control while driving
Mouse wheel up Boat radar on / off (in a boat)
Esc Back (inside an app), or closes the tablet

All keys can be changed under Options → Controls → Expansion Plus.

Cruise control#

While driving a car, motorbike or boat, press the cruise key to hold your speed. Up / Down arrow change it by 5 km/h (hold to keep changing). The cruise key again, the brake, the handbrake, reversing a boat, stopping the engine or leaving the seat turn it off. Accelerating still speeds you up, and cruise picks up again when you let go.

Boat radar#

In a boat, a small round radar sits in the bottom-right corner: 500 m range, heading-up, with a sweep line. Vehicles show orange, people white, boats blue. Mouse wheel up turns it on or off.
