Settings reference#

Every setting is editable in game and saved on the server. Switches: 1 = on, 0 = off.

Where In game File
Main settings F8 → SETTINGS profiles/GhostzSuite/Settings.json
Garage settings F8 → GARAGE ADMIN → SETTINGS profiles/GhostzSuite/Garage.json
Stock exchange F8 → STOCK EXCHANGE profiles/GhostzSuite/Stocks/Settings.json
Workshop apps F8 → ALL TOOLS → QOL ADMIN CONTROL profiles/GhostzQoLPlus/<App>.json

New settings appear with their defaults after an update; nothing needs migrating.
