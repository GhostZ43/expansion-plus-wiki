Admins

Workshop Admin Control#

Admins open it from F8 → QOL tab. It opens inside the F8 admin panel as its own tab; the Back key closes its sub-panels first.

Page What admins do there
DASHBOARD Status of every module, notices, admin changes, refused requests, RELOAD FILES
INVENTORY Inventory Manager settings
STACKING Stack-size presets and overrides, GENERATE PATCH
RECIPES The recipe builder
REPAIRS Repair rules and costs
DRYING Fee, batch size, cooldown
LOOT SCANNER Price, radius, cooldown, results, marker time, categories
VEHICLES Vehicle Dashboard options
VALUATION Appraisal options
PAYMENTS Not used with Expansion Plus (fees use Expansion Plus money)
BACKUPS MAKE BACKUP, RESTORE SELECTED
ADMINS The Workshop admin list

Every settings page edits the module's own file in profiles/GhostzQoLPlus/. Values are checked and clamped on the server, and every change goes in the audit log.

Who can use it#

Role Can
owner Everything
admin View and change settings
readonly View only

Expansion Plus full admins are owners, staff with the settings right are admins, and other staff are read-only. profiles/GhostzQoLPlus/Admins.json still works for anyone you add there.

Stack-size patch#

Stack sizes are game config values, so they need a small extra addon:

  1. STACKING: choose an ammo preset (30–200), an item preset (20–50) and any per-class overrides, then GENERATE PATCH.
  2. The server writes the patch source to profiles/GhostzQoLPlus/StackPatch/.
  3. Drag that folder onto @GhostzSuite/Tools/BUILD_STACK_PATCH.bat (needs Python 3).
  4. Load the new @GhostzQoLPlus_StackPatch last on the server and give it to players, then restart.
