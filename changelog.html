Changelog#

1.21.0 – Shop buildings (2026-11-12)#

  • Ghostz Shops built in: player shops are now buildings (Abandoned Shop, Little Shop, Minimarket) with working doors, a blueprint for placing and a storage chest. Remove @GhostzAbandonedShop. Old container shops pack up automatically and owners get a kit. See Updating to 1.21.
  • Claim a shop by naming it on its sign; the name shows on the sign, the tablet and the map.
  • SELL TO SHOP (owner pays) or SELL TO TRADER (server pays), both prices shown; SELL ALL (BEST PRICE).
  • Admins switch Expansion trader categories on per shop and set the seller %, the owner's cut and whether the owner keeps sold items.
  • Garage: tow anywhere after a set time unused, even in parking areas, with a release fee. Tow timers count server time only, so restarts never reset them or add downtime.
  • Garage: vehicles kept across restarts: snapshots every 10 minutes; fallen or flung vehicles are put back, missing ones rebuilt; tracked vehicles never time out of storage.
  • Rentals: fixed renting doing nothing at some traders (any Expansion trader zone counts); RENT always says why it can't rent.
  • Tablet: new backgrounds Misty Peaks and Dragon Dusk.

1.20.1 – Garage retrieval fix (2026-11-11)#

  • Taking a vehicle out of the garage no longer deletes its stored file until the garage database has saved; if anything fails, everything is put back.
  • Player take-out and admin SPAWN HERE use the same path. A slot whose file is missing is kept, and you're told which slot.
  • New GARAGE RESTORE lines in the script log.
  • New QOL tab in F8 for the Workshop settings; the ALL TOOLS buttons are now QOL SETTINGS.
  • The tablet's Back / Home / Forward keys no longer show numbers over the bezel.

1.20.0 – One Tablet (2026-11-11)#

  • Ghostz QoL Plus built in: Inventory, Crafting, Repair, Drying, Appraisal, Loot Scanner and Vehicle Dashboard open inside the tablet. Remove @GhostzQoLPlus from servers. See Updating to 1.20.
  • Ghostz Tab 10.1: a physical tablet frame round every screen, with Back / Home / Forward keys and page history.
  • Hubs on the home screen: Finance, Garage, Workshop, Trade, Jobs, Territory, Intel, Social. Quick Status strip. Backgrounds moved to Settings.
  • Drying Station as a washer-dryer; Loot Scanner radar scope.
  • Workshop fees paid with Expansion Plus money and logged in Transactions.
  • One admin list for everything; F8 ALL TOOLS tab; stack patch builder in @GhostzSuite/Tools.
