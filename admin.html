Admins

Admin panel (F8)#

Admins press F8. Every change is saved on the server at once. Dangerous buttons (delete, wipe) need a second click, and every admin action is logged with the admin's name.

ALL TOOLS#

The first tab lists every admin page, grouped like the player hubs:

Group Pages
Finance BANKING, STOCK EXCHANGE, ECONOMY
Garage GARAGE ADMIN, RENTALS, TRACKERS
Workshop QOL tab (Workshop admin)
Trade SHOPS, MARKET, RESTOCK, TRADE LOG
Jobs CONTRACTS
Territory TERRITORY, AUDIT, CONTROL ZONES
Intel MAP MARKERS, QOL tab (scanner)
Server SETTINGS, PLAYERS, INBOX, INFO, APPS, ADMIN LOG, FILES

Tabs#

Tab What admins do there
INBOX Read, answer and delete player calls and reports
INFO Edit the F9 page and the tablet's Links; reset all stats
SETTINGS Every setting in plain-English groups; add or remove admins
SHOPS View, rename, set funds, teleport, delete; switch Expansion trader categories on per shop and set its trader terms (seller %, owner's cut, owner keeps sold items)
TERRITORY Teleport, +7 days free, delete flag, wipe all; rent history
AUDIT Rank the biggest bases by object count, with teleport and wipe
RENTALS Make market vehicles rentable, set time and cost; end rentals
TRACKERS Every tracked and rented vehicle: teleport, untrack
CONTRACTS Running and open jobs, courier routes, random points
PLAYERS Bank accounts: set a balance, GIVE MONEY with a reason, wipe bank, territories or everything
TRADE LOG Every Expansion market purchase and sale, with filters
MARKET The market editor
RESTOCK Restock a trader
ECONOMY Money in circulation, created and destroyed per day, top earners, big-payment alerts
ADMIN LOG Every admin action, with search and UNDO for bank changes, wipes, money given, restocks and shop funds
FILES Editor for Expansion's .json and .map files, with real JSON checks and a backup before every save

The footer opens BANKING, CONTROL ZONES, MAP MARKERS, APPS, STOCK EXCHANGE, GARAGE ADMIN and TABLET HOME.

Admin roles#

Admins in Settings.json are full admins. Optional AdminRoles give narrower admins only their part of F8:

"AdminRoles": [ { "Steam64": "76561198000000000", "Role": "economy" } ]
Role Can use
owner, full Everything
senior Everything except the admin list
moderator Players, tickets, logs
event World tools, tickets
vehicle Vehicles
economy Economy, market, shops
readonly View only

Every action is checked on the server and refusals are logged. Optional UseAdminPlusRights links roles to Admin Plus rights (off by default). The same list also decides who can use the Workshop admin.

Apps#

F8 → APPS locks any tablet app: players lose it, admins keep it (marked (locked)). It also sets whether players can deposit and withdraw cash anywhere or only at Expansion ATMs.

Control zones#

Add zones with a name, kind, radius (10–2000 m) and colour, centred where you stand or picked on the map. EDIT, DELETE, FREE IT and PAY NOW. Settings cover incomes, minutes to take, bonus %, payout hours, split or full pay, and production.

Map markers#

Add, edit and delete Expansion server markers: a name, a position (or USE MY POSITION), an icon from Expansion's full icon list with pictures and a search, a colour slider, and map, world or both. Saved into Expansion's MapSettings.json.

Server info#

F8 → INFO edits the F9 page (title, welcome lines, rules, wipes, restart times, events, links) and the tablet's Links button. RESET ALL STATS starts every player's stats again; PREVIEW shows the page.
