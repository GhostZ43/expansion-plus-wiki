Admins

Admin panel (F8)#

Admins press F8. Every change is saved on the server at once. Dangerous buttons (delete, wipe) need a second click, and every admin action is written to GhostzSuite.log with the admin's name.

Tab What admins do there
INBOX Read, answer and delete player calls and reports
INFO Edit the F9 page; reset all stats
SETTINGS Every setting in plain-English groups; add or remove admins
SHOPS View, rename, set funds, teleport, respawn the container, delete
TERRITORY Teleport, +7 days free, delete flag, wipe all; rent history
AUDIT Rank the biggest bases by object count, with teleport and wipe
RENTALS Make market vehicles rentable, set time and cost; end rentals
TRACKERS Every tracked and rented vehicle: teleport, untrack
CONTRACTS Running and open jobs, courier routes, random points
PLAYERS Bank accounts: set a balance, wipe bank, territories or everything
TRADE LOG Every Expansion market purchase and sale, with filters
MARKET The market editor
RESTOCK Restock a trader
FILES Line-by-line editor for .json and .map files in profiles/ExpansionMod and mission/expansion

The footer opens BANKING, CONTROL ZONES, MAP MARKERS and GARAGE ADMIN.

Control zones#

Add zones with a name, type, kind (income), radius (10–2000 m) and colour, centred where you stand or picked on the map. EDIT, DELETE, FREE IT and PAY NOW. Settings cover incomes, minutes to take, bonus %, payout hours and split or full pay.

Map markers#

Add, edit and delete Expansion server markers: a name, a position (or USE MY POSITION), an icon from Expansion's full icon list with pictures and a search, a colour slider, and map, world or both. They're saved into Expansion's MapSettings.json.

Server info#

F8 → INFO edits the F9 page: title, welcome lines, rules, wipes, restart times, events and links. RESET ALL STATS starts every player's stats again; PREVIEW shows the page.
