Reference

Files and folders#

Everything Expansion Plus saves is in profiles/GhostzSuite/ and, for the Workshop apps, profiles/GhostzQoLPlus/ on the server. Back it up with the server's storage folder. Players' own choices (tablet background, message sound) are saved in their game profile, not on the server.

File or folder Holds
Settings.json Main settings and the admin list
Garage.json Garage settings and parking / dealer zones
Garage/Garage.json Stored vehicles, vehicles in the world, impounds, listings
Garage/ One saved file per stored vehicle
Garage/out/ Snapshots of vehicles out in the world, used to put back or rebuild them after a restart (old ones are cleaned up automatically)
Bank.json Savings, group accounts, loans, the bank log
Transactions/ Each player's bank transactions
Shops.json, Shops/Index.json Shop list and the next shop number
Shops/Shop_<id>_<steam64>.json One file per shop: owner, name, building, funds, listings, stock, storage, ratings, trader categories and terms
Rent.json Each territory's paid-until date and total paid
RentHistory.json Every rent payment, free day and flag removal
Vehicles.json Active rentals and tracked vehicles
Contracts.json Courier jobs, routes and points
ControlZones.json Control zones, holders and their settings
Bounties.json Live and finished bounties
Donations.json The donation box and cooldowns
Messages/Messages.json, Messages/Contacts.json Messages, admin calls, contacts and blocks
ServerInfo.json The F9 page and the tablet's Links
Notifications.json Each player's pop-up and sound choices
Economy.json Money created, destroyed and moved per day
AdminLog.json Every admin action (with undo data)
Stocks/Settings.json, Stocks/Market.json, Stocks/Accounts.json Stock exchange settings, prices and news, investment accounts
Stats.json, Reviews.json Player stats and reviews
TradeLog.json Expansion market trades
Names.json Last known name for each player ID
Backups/ Verified copies of Expansion files from before the editors changed them (Backups/work for temporary copies)
GhostzSuite.log Everything the mod and admins did, with times

Expansion Plus also writes to Expansion's own files when admins use the market editor, RESTOCK (trader zone files) or MAP MARKERS (MapSettings.json).

Workshop apps (profiles/GhostzQoLPlus/)#

File or folder Holds
General.json Which Workshop apps are on, log detail, request spacing
Admins.json Extra Workshop admins (owner / admin / readonly)
Inventory.json, Repairs.json, Drying.json, Scanner.json, Vehicles.json, Valuation.json, Stacking.json Each app's settings (reference)
Payments.json Not used with Expansion Plus (kept for reference)
CraftingRecipes.json Every recipe
Crafting_Pending.json Crafted items waiting to be collected
Backups/ Backups made in Workshop Admin Control
Logs/Audit.log Every Workshop admin change
StackPatch/ Generated stack-size patch source

Safe saving#

Every file is written to a temporary copy, read back and checked, the current file is copied to a verified .bak, and only then is it replaced. A file that can't be read is kept as <file>.broken_<date-time> and its backup is loaded instead; it's never reset to empty.
