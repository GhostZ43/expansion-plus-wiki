Getting started

Updating to 1.20#

Expansion Plus 1.20.0 brings Ghostz QoL Plus inside: one mod, one tablet, one admin panel. Nothing is wiped.

Server checklist#

  1. Back up profiles/GhostzSuite and profiles/GhostzQoLPlus.
  2. Update @GhostzSuite.
  3. Remove @GhostzQoLPlus from the server's -mod list and from your modlist or launcher.
  4. Keep keys/Ghostz.bikey (same key as 1.18).
  5. Restart.

Warning

Loading @GhostzQoLPlus together with Expansion Plus 1.20 stops the server starting, because the same code would be loaded twice.

What is kept#

Data Where Kept?
Expansion Plus settings and data profiles/GhostzSuite/ Yes, unchanged
Workshop app settings (modules, prices, limits) profiles/GhostzQoLPlus/*.json Yes, read as before
Crafting recipes profiles/GhostzQoLPlus/CraftingRecipes.json Yes
Crafted items not yet collected profiles/GhostzQoLPlus/Crafting_Pending.json Yes
Workshop admins profiles/GhostzQoLPlus/Admins.json Yes, and Expansion Plus admins now count too
Bank balances Expansion's own ATM data Yes, untouched
Players' F5 key binding the player's game Yes, same action

What changes#

  • Payments: Workshop fees (crafting, repair, drying, scanner) are paid with Expansion Plus money: the player's BANK / CASH choice on the tablet, using the other if the first is short. Each charge shows in Transactions. QoL's Payments.json (PayWith, CashItems) is no longer used. Fee amounts are unchanged.
  • F5 now opens the Expansion Plus tablet on the Workshop hub. The old rusted PDA is gone.
  • Admins: Expansion Plus Admins and AdminRoles count for the Workshop apps (full admin = owner, settings rights = admin, other staff = read-only). Admins.json still works.
  • The stack-size patch builder moved to @GhostzSuite/Tools.

Players#

Players unsubscribe from Ghostz QoL Plus and update Expansion Plus. Their tablet background and message sound are kept.
