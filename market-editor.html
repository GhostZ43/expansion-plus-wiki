Admins

Market editor#

F8 → MARKET edits Expansion's market without touching JSON.

Traders#

profiles/ExpansionMod/Traders

  • Display name, icon, currencies, reputation limits, required faction and category order.
  • Add or remove categories and set each to BUY + SELL, BUY ONLY or SELL ONLY.
  • Add or remove single items. Create or delete trader files.

Categories#

profiles/ExpansionMod/Market

  • Display name, icon, colour, starting stock % and exchange flag.
  • Add, edit or delete items: lowest and highest price, lowest and highest stock, sell %, quantity %, attachments and variants.
  • Items that aren't real game classes are flagged red. A classname can only be in one category.
  • Deleting a category also removes it from every trader.

Trader locations#

mission/expansion/traders/*.map

  • Change an NPC's class, trader file, position, orientation and clothes.
  • USE MY POSITION moves it to where you stand; TELEPORT takes you to it.
  • ADD NPC HERE places a new one; DELETE NPC removes one.

Tip

Files are checked as real JSON and can't be saved when invalid. Market files are also checked for missing class names, duplicates, prices, stock and unknown classes (these warnings still allow a save with a second click). Every file gets a verified backup in profiles/GhostzSuite/Backups/ before it's changed. Expansion reads market files only at start-up, so restart to see your edits.
